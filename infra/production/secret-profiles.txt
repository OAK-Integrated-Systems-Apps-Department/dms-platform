# Secrets that are only needed in some setups. One per line: <profile> <KEY>.
# Every key here is also listed in secret-keys.txt (that file is the whole set,
# used to store and render secrets); this file says when one may be absent.
#
#   <service profile>  needed only while that bundled service runs (it is in
#                      COMPOSE_PROFILES in .env). A client using its own
#                      database or object storage does not have them.
#   optional           never required; passed through when present (credentials
#                      for the client's own S3 / Azure Blob, a separate Keycloak
#                      database login).
#
# deploy.sh requires the others to exist before it changes anything; the OpenBao
# renderer and importer skip any key here that is not stored.
